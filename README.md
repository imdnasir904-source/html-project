# HTML Learning Roadmap – Beginner to Advanced

### Group 1: HTML Document Structure

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<title>`
- `<meta>`
- `<body>`

### Group 2: Text and Content Formatting

- `<h1>` – `<h6>`
- `<p>`
- `<br>`
- `<hr>`
- `<strong>`
- `<b>`
- `<em>`
- `<i>`
- `<span>`

### Group 3: Links and Lists

- `<a>`
- `<ul>`
- `<ol>`
- `<li>`

### Group 4: HTML Elements, Attributes and Containers

- Elements and attributes
- `class` attribute
- `id` attribute
- `<div>`
- `<span>`
- Nesting elements
- Parent-child relationships

### Group 5: Semantic HTML and Page Layout

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`

### Group 6: Images and Multimedia

- `<img>`
- `<figure>`
- `<figcaption>`
- `<audio>`
- `<video>`
- `<source>`
- `<iframe>`

### Group 7: HTML Tables

- `<table>`
- `<caption>`
- `<thead>`
- `<tbody>`
- `<tr>`
- `<th>`
- `<td>`

### Group 8: HTML Forms and Input Elements

- `<form>`
- `<label>`
- `<input>`
  - text
  - password
  - email
  - number
  - date
  - checkbox
  - radio
  - file
  - submit
- `<textarea>`
- `<select>`
- `<option>`
- `<button>`

### Group 9: Form Validation

- `required`
- `min`
- `max`
- `minlength`
- `maxlength`
- Input type validation
- Basic form validation

### Group 10: Interactive and Disclosure Elements

- `<details>`
- `<summary>`
- `<dialog>`

### Group 11: Progress and Measurement Elements

- `<progress>`
- `<meter>`

### Group 12: Accessibility and Semantic Best Practices

- Alt text
- Accessible labels
- Semantic HTML choices
- Correct nesting
- Valid HTML markup

### Group 13: Connecting CSS and JavaScript

- `<link>` – Linking CSS stylesheets
- `<script>` – Loading JavaScript
- `href`
- `src`
- `defer`

### Group 14: Browser Developer Tools

- Elements / Inspector
- Styles
- Console
- Network
- Responsive Design Mode
- HTML debugging

### Group 15: Complete HTML Project

- Rebuild a complete webpage
- Create page structure
- Add navigation
- Add content and multimedia
- Create tables and forms
- Apply semantic HTML
- Connect CSS and JavaScript
- Test and debug the webpage
